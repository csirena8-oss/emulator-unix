# Примеры для этапа 2

## Стартовые скрипты эмулятора (`.esh`)

- `demo.esh` — демонстрация всех команд этапа 1 и обработки ошибок.
- `errors.esh` — демонстрация ошибок и завершения по концу файла  
  (без команды `exit`).

Синтаксис скрипта:

- одна команда на строку;
- строки, начинающиеся с `#`, — комментарии (синтаксис Python);
- пустые строки игнорируются.

## Файл VFS

`samples/vfs.zip` — путь к физическому расположению VFS.
На этапе 2 он **не загружается** и служит только для проверки  
проброса параметра `--vfs` в отладочный вывод. Реальная загрузка  
VFS будет реализована на этапе 3 (файл будет создан отдельно,
чтобы не нарушать запрет на бинарные файлы в репозитории).

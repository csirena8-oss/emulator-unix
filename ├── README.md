# Эмулятор командной строки (Вариант 25, этап 1)

## 1. Общее описание

Учебный проект — минимальный прототип UNIX-подобной оболочки,
реализованный в виде REPL (read-eval-print loop).

На первом этапе поддерживается:

- интерактивное приглашение, построенное на реальных данных ОС;
- разбор введённой строки на имя команды и аргументы;
- раскрытие переменных окружения `$NAME` и `${NAME}`;
- обработка ошибок (неизвестная команда, неверные аргументы);
- заглушки команд `ls` и `cd`;
- команда `exit` для выхода из REPL.

Запускать в терминале UNIX-подобной системы с установленным  
Python 3.9+.

## 2. Описание функций и настроек

### 2.1. Модуль `src/shell_emulator.py`

| Функция | Назначение |
|---------|------------|
| `current_user()` | имя пользователя (`getpass.getuser()`); |
| `current_host()` | имя хоста (`socket.gethostname()`); |
| `display_cwd()` | текущий каталог, `~` для домашнего пути; |
| `build_prompt()` | строка приглашения `user@host:dir$`; |
| `expand_env(token)` | подстановка `$NAME` и `${NAME}`; |
| `parse_line(line)` | разбор строки на команду и аргументы; |
| `report_error(name, msg)` | вывод ошибки в `stderr`; |
| `command_ls(args)` | заглушка `ls`; |
| `command_cd(args)` | заглушка `cd`; |
| `build_registry()` | словарь имён → обработчиков; |
| `dispatch(reg, name, args)` | поиск и вызов команды; |
| `run_repl()` | цикл чтения-выполнения-печати; |
| `main()` | точка входа. |

### 2.2. Настройки (константы модуля)

| Константа | Значение | Смысл |
|-----------|----------|-------|
| `PROMPT_END` | `"$ "` | завершающая часть приглашения; |
| `HOME_SHORTCUT` | `"~"` | обозначение домашнего каталога; |
| `MAX_CD_ARGS` | `1` | максимум аргументов для `cd`; |
| `EXIT_COMMAND` | `"exit"` | имя команды выхода; |
| `ENV_PATTERN` | regex | шаблон `$NAME` / `${NAME}`. |

### 2.3. Тесты `tests/test_shell_emulator.py`

Покрывают: раскрытие переменных окружения, разбор строки,
заглушки `ls` / `cd`, обработку неизвестных команд, корректный  
выход из REPL по `exit` и `EOFError`.
